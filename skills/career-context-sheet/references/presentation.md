# Present a work register

Use Build context, My context (Timeline, Work and optional Skills) and Profile as the main navigation. The five context activities are collection, review, meaningful gaps, connections and voice. Practice and Sources stay secondary in the footer; preserved practice links do not imply a required preparation task. Work opens on its accounts and controls; the overview and career background remain available in disclosure. Use one visual system and one portable packet across the views. Do not add a marketing hero, decorative pipeline or invented score.

## Composition

Use a continuous light surface, strong typographic hierarchy and shared alignment lines. Keep the overview substantial only when it adds a supported connection across accounts. Number accounts for navigation, never as a ranking. A compact export area belongs with the Work heading and filters; it must say what will be copied and which files contain private source text.

Work titles and one to three short supported bullets carry the page; the original account remains under disclosure. Group a substantial list by relationships in the actual work, using the person's words. Keep career background separate. No profession, industry or universal category list is prescribed. Keep dates distinct from source capture dates. Place material limitations beside the relevant claim. Disclose detailed contribution, decisions and sources beneath the account. Skills & tools links lead to the same work, with assistance and limits retained there. A tool label alone is not a claim of proficiency. The timeline connects periods to these accounts; preparation connects questions, answers and story chapters to the same evidence.

Use a small spacing vocabulary and one edge per boundary. Avoid nested cards, decorative badges and repeated provenance paragraphs. Controls, metadata, sources and the ending use the same type and surface system. Preserve existing brand choices when supplied.

## Interaction

Search the account text and capabilities locally. Skill selection narrows accounts; it never changes their underlying facts. Empty results have a clear reset. Link navigation must reveal the destination even after filtering. Keep text readable immediately; finite icon feedback is enough for this reading surface. Reduced motion removes transitions.

Keep global navigation reachable in each view. Direct links, refresh and back/forward retain the selected period or story. Copy scope defaults to visible work accounts. Entering from Timeline or changing a Work filter restores that scope; the person can explicitly choose all accounts or one account. Name a period filter “Related to [period]”: linked accounts may span other dates. Full-file export remains separate from scoped copying. Scoped work copying omits unrelated overview, timeline, preparation and presentation metadata. Review and gap investigation are the main Work continuations. An optional link leads to a prepared Practice story, or to “Prepare this story” with an account-only prompt for the preferred assistant. This is a handoff, not an in-page model call or an automatically saved story. Both routes return to the originating account; destination links reveal records hidden by earlier filters. Full HTML and JSON preserve all views, sources and saved rehearsal notes; reading filters never sanitize them. Printing includes all views and restores the reading state afterward. Without JavaScript, all substantive material remains readable; hide nonfunctional controls.

## Finish

Check a sparse account, a long grouped archive, background disclosure and an absent skills index. From a selected period, verify filtered work, copied scope, account review and the return. Reach Profile without practising. Verify withheld components disappear from preview and public export while remaining in private saves; returning to Edit must retain their wording. Check prepared and unprepared Practice routes as optional uses. Use nontechnical raw notes with an unfinished episode and shared credit; do not preload a role or a polished narrative. Exercise source links, filters, empty state, keyboard disclosures, clipboard fallback, downloads, reopening and print. Inspect 320, 375, 768 and desktop widths, including expanded content. Preserve exact evidence and the selected image bytes. State checks that could not run; source inspection alone is not rendered verification.

Profile keeps a visible selected-content count beside its download action. Show the selection controls on entry, including independent choices for North Star, direction, example details and work samples. Read the selected preview as one story: purpose, meaningful changes, distinctive examples and relevant visual evidence. Each part must add information; repeated role labels or year summaries do not show progression. Withhold an example and recheck any remaining caption or claim that referred to it; include a previously withheld progression period and check that the date order still makes sense. Use [progression and direction](progression-and-direction.md) for the content decisions and [visual evidence](visual-evidence.md) for genuine work samples and version limits. Public exports are local files; collapsed details are still shared.

Profile Edit provides Move up and Move down for progression periods. Reordering must retain every period's wording and sharing choice; preview, export and private saves use that same order. Keep focus on the moved period's enabled control. Do not guess dates from ambiguous period labels or require deleting a period to reposition it. Verify the full saved list, including unselected periods, then check the selected reading again.

Invalid video links stay as private drafts with a field-specific error, including after reopening Edit or restoring a save. A disabled work-sample choice names what needs fixing in Edit. Keep the sharing choice disabled until the link is valid; correcting it must not automatically select it. A warning for one link must not disappear when a different link is edited. Verify these saved/error states separately from valid exports.
