# Career Context AI — start here

Give your assistant this project and, if you have one, your latest private career-context file:

> Follow the career-context starter. Reuse my existing context, check what this environment can actually read and save, and help me build one useful account from material I authorize. Preserve shared credit, uncertainty and my corrections. Save progress so we can continue later.

**Assistant:** follow [the starter](skills/career-context-sheet/START-HERE.md), then its skill. Check capabilities before promising an archive. Continue in this conversation; do not make the person manage the research steps. Access to this public project grants no access to their private files or connected accounts.

If this host cannot read project folders, use its supported file-upload or skill-installation route for the complete `skills/career-context-sheet` package. An assistant with project file access can produce that ZIP with `python tools/build_skill.py OUTPUT.zip`. Do not upload private career files as part of the skill package.

The [fictional example](CAREER-CONTEXT.html) can be downloaded and opened in a browser. It is a reading and review surface; it does not contain an AI connection. [Setup and supported fallbacks](docs/GETTING-STARTED.md).

After working in the sheet, choose **Save for assistant**. Attach that one file and say “Continue my career context.” The file carries its own resume instructions; you do not need to copy another prompt.

The assistant should keep investigating and challenging the account through useful rounds, saving what changed and what to read next. You supply access, corrections and personal meaning; you should not have to manage each research pass.
